## 1. Matemática verificada: el "libro" que se demuestra a sí mismo

Este es probablemente el cambio de medio más profundo que está ocurriendo en matemática. **Lean 4** con **Mathlib** permite escribir definiciones y demostraciones que la máquina verifica. Ya no es un nicho: Terence Tao y otros lo usan en proyectos reales de investigación. Hay dos piezas clave para producir conocimiento con esto. La primera es **leanblueprint** (de Patrick Massot), que genera un documento LaTeX navegable con un grafo de dependencias entre lemas: verde lo demostrado, azul lo pendiente. La segunda es **Verso**, el sistema de documentación de Lean para escribir textos donde cada fórmula está vinculada a código verificado.

Para tus modelos teóricos de finanzas o tus diseños de modelos matemáticos, un blueprint verificado es un producto cualitativamente distinto a un PDF. En criptografía el análogo es **EasyCrypt**, **CryptoVerif**, **Tamarin** o **ProVerif** para pruebas de seguridad, y **Cryptol/SAW** (de Galois) para verificar que una implementación coincide con la especificación.

## 2. Documentos computacionales: texto, código y resultados en un solo objeto

Es la evolución directa del paper. Lo más fuerte hoy:

- **Typst**: un reemplazo moderno de LaTeX. Compila en milisegundos, tiene un lenguaje de scripting real y mensajes de error legibles. LaTeX sigue siendo obligatorio para publicar, pero para apuntes, informes y material propio Typst es otra experiencia.
- **Quarto**: desde una sola fuente (Markdown + Python/R/Julia) genera paper en PDF, sitio web, libro, slides y dashboards. Es el pegamento ideal para alguien que ya usa Python, R y LaTeX.
- **marimo**: notebooks *reactivos* de Python, almacenados como archivos `.py` puros (versionables en Git sin el caos de JSON de Jupyter). Se exportan como apps web que corren en el navegador vía WebAssembly (Pyodide), sin servidor.
- **MyST / Jupyter Book**: para libros técnicos con referencias cruzadas serias.

## 3. Explicaciones explorables: la matemática que se manipula

Es la tradición de Bret Victor y de la revista *Distill*: el lector no lee que un parámetro cambia el sistema, lo mueve y lo ve.

## 4. Simulación de alto rendimiento: laboratorios virtuales
